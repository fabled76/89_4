## Recommendation for this project

Prefer a **bounded rigged offline3D→2D character proof** if the owner is willing to obtain/approve one suitable mesh/rig. It fits the already verified18° camera and physical lamp source, and reduces repeating the angle/light problem per pose. This is a production recommendation from the working scene, not character/art approval or a promise of low initial labour.

Choose the photographed route if an accessible, approved controlled shoot is the owner's stronger resource. First check one still against the actual camera/foot anchors before buying into cutout animation. Do not use a random catalogue/person image or independently generated frames to fill the missing source.

For either path the next separately authorized test would be one idle and a short horizontal traverse, with fixed physical height/foot support and the existing light profile. It must reveal foot sliding, edge/occlusion and anatomical drift. No test/rig/frame set has been produced in v03, and no invented hour estimates or cast decisions are supplied.
