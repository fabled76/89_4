# 89.4 — current playable

Open in Unity **6000.3.8f1**, wait for compilation, then choose **89.4 → Play Current Game**. This opens `Assets/_Game/Scenes/CurrentPrologue.unity` and enters Play mode. Click Game view and use 16:9 with Gizmos off. CurrentPrologue is also the first enabled Build Settings scene; SampleScene is historical, not the current entry.

Connected route: painted home prologue → travel → motel registration → own room → ordinary corridor conversation without receiver → retrieve/check receiver → empty corridor. No manual scene opening between these beats. Morning inquiry is not implemented.

- **A/D:** walk horizontally; during reading, previous/next or finish.
- **E:** nearest valid interaction. **Esc:** close reading.
- **Left Shift:** radio power; in the motel, only after explicit receiver retrieval.
- **F1**, then **1/2:** English/Russian. Locale persists; gameplay progress does not.

Assigned working art includes corrected floor backgrounds, home/outdoor hero variants, man, separate bag/receiver and contact shadows. Runtime sound includes ordinary ambience, movement/doors/handling, switches/texture and an English synthetic announcement. RU uses readable program text with receiver texture. **A complete music program/score is not supplied.**

See [current setup, assignments, screenshots and verification](Docs/CURRENT_PLAYABLE_SETUP.md). Historical scenes remain directly testable; their reports describe those versions rather than the recommended current route. Do not rerun old builders to replace the current scenes.
